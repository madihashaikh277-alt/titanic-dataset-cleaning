# Titanic Dataset Cleaning Using Python

## Project Overview
This project cleans the public Titanic dataset using Python and the Pandas library.

## Dataset
The dataset contains passenger information from the Titanic, including age, gender, passenger class, fare, and survival status.

## Data Cleaning Steps
- **Missing values:** Filled missing Age values with the median, Cabin values with "Unknown", and Embarked values with the mode.
- **Duplicate records:** Checked for duplicate rows. No duplicate rows were found.
- **Data types:** Checked the data types. No incorrect data types were identified.
- **Inconsistent values:** Checked Sex and Embarked values. No inconsistencies were found in these columns.

## Final Results
- Total rows: 891
- Total columns: 12
- Missing values after cleaning: 0
- Duplicate rows: 0

- Python
- Pandas
- Google Colab
